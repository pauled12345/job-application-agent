## Q14 — Describe your best personal software project, outside of curriculum

AutoIntel, an AI-assisted vehicle diagnostics and maintenance app.

It connects to a vehicle over a Bluetooth ELM327 OBD-II scanner, reads
diagnostic trouble codes and live sensor data, and uses an LLM to turn those raw
codes into plain-language explanations and maintenance guidance that a
non-expert owner can act on. The mobile client is Flutter; the backend is
FastAPI with a PostgreSQL database storing diagnostic results, maintenance
history, fuel records and repair costs.

I chose this because I wanted to build something with a real user rather than
another tutorial project. The hard part was not the API calls, it was deciding
how much the model could be trusted. Wrong maintenance advice has safety
consequences, so I spent most of my effort on prompt behaviour, output accuracy,
and making sure the app degrades gracefully when the model is unsure.
